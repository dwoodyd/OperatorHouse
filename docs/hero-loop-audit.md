# Hero Loop: Lead → Audit → Vault-Grounded Strategy → Outreach

The primary Operator House demonstration path is intentionally linear. A user submits a real prospect to **Lead Intelligence**, receives a structured Specter audit, then chooses **Build Vault-grounded Strategy**. The strategy page carries the audited facts forward in browser-session memory and clearly identifies that the audit has been loaded.

Strategy generation continues to use the existing server-side Vault grounding and citation response. The result panel exposes the returned Vault sources as visible citation chips so the operator can inspect the factual basis of each recommendation rather than treating the output as an unexplained draft.

The strategy result offers **Prepare outreach from this strategy**. That action passes the generated strategy, again only for the active browser session, into Email Sequences. The receiving page identifies the intended prospect and exposes a one-click copy action for the strategy context, allowing the operator to tailor an existing Soul Engineer sequence before enrolling a real client. No fabricated leads, clients, messages, reviews, or performance data are introduced anywhere in this flow.
